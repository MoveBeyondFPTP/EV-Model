These are preliminary projections, not forecasts. Each one starts from the state’s 2024 result shifted by the national generic ballot, blends in that race’s polling average, and, in states with party-registration early-vote data, nudges it by a capped turnout signal. The range shows how far apart those inputs are. Polling misses can be larger. Open a state to see every input and the polls used.
